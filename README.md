##  AI-Powered Student Academic & Well-Being Platform

An integrated AI-driven web application that unifies academic tracking, productivity management, and mental-health monitoring for students, with real-time counselor interaction and intelligent insights powered by Hugging Face NLP models.

Visit: https://student-academic-well-being-platfor.vercel.app/

---
## 🚀 Project Highlights
- Full-stack AI-enabled platform supporting both academic performance and student well-being
- Role-based dashboards for Students and Counselors
- NLP-based sentiment analysis using Hugging Face transformer models
- AI-assisted task and assignment guidance
- Designed with scalability, privacy, and real-world usability in mind

---

## 🧩 Core Features

### Student Module
- Unified dashboard for tasks, study progress, appointments, and AI chat
- Task and assignment management with AI assistance
- Study session tracking with productivity insights
- AI-powered journaling with sentiment analysis
- Automatic alerts on prolonged emotional patterns
- Counseling appointment booking and management
- Resource organizer and crisis support access

### Counselor Module
- Counselor dashboard with workload and student insights
- Appointment management system
- Student engagement and activity overview
- Secure resource library with private counseling notes

---

## 🤖 AI Capabilities
- Sentiment analysis using Hugging Face Transformer models
- Mood trend detection and early-risk flagging
- Personalized academic and well-being recommendations
- AI chatbot for academic guidance and wellness support
- Human-in-the-loop escalation for high-risk cases

---

## 🛠️ Tech Stack

- Frontend: React.js
- Backend: Node.js, Express.js
- Database: MongoDB
- AI / NLP: Hugging Face Transformers (Sentiment Analysis)
- Authentication: Role-based access control
